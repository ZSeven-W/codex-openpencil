# Ecosystem icons

These assets are copied without modification from the projects they identify.
The READMEs display them at 40 CSS pixels wide while preserving their aspect
ratios. OpenPencil reuses this repository's existing
[`plugins/openpencil/assets/icon.png`](../../../plugins/openpencil/assets/icon.png).

| File | Source |
| --- | --- |
| `dsh-openpencil.png` | [DSH OpenPencil README logo](https://github.com/ZSeven-W/dsh-openpencil/blob/main/docs/images/dsh-openpencil-logo.png) |
| `dsh-crew.png` | [DSH Crew README logo](https://github.com/ZSeven-W/dsh-crew/blob/main/docs/images/dsh-crew-logo.png) |
| `jian.png` | [jian icon in the Rish ecosystem](https://github.com/ZSeven-W/rish-app/blob/main/docs/images/ecosystem/jian.png) |
| `zode.png` | [Zode icon in the Rish ecosystem](https://github.com/ZSeven-W/rish-app/blob/main/docs/images/ecosystem/zode.png) |
| `noema.png` | [noema icon in the Rish ecosystem](https://github.com/ZSeven-W/rish-app/blob/main/docs/images/ecosystem/noema.png) |
| `rish-app.png` | [Rish Android launcher icon](https://github.com/ZSeven-W/rish-app/blob/main/apps/mobile/android/app/src/main/res/mipmap-xhdpi/ic_launcher_round.png) |

Brand assets retain their upstream terms. In particular, the Rish icon is
excluded from Rish's MIT license and is reproduced unmodified to refer to the
project, as permitted by its [brand policy](https://github.com/ZSeven-W/rish-app/blob/main/brand/README.md).

Projects without a published project icon keep a text entry in the ecosystem
table. Design examples and screenshots are not used as substitute logos.
